PostaAi

Personal video publishing tool · Ferramenta pessoal de publicação de vídeos

PostaAi is a private, single-user tool that runs only on its owner's computer. It renders short vertical videos produced by the owner (a Brazilian music quiz and a daily Bible verse) and uploads them, through the YouTube Data API, to the owner's own two YouTube channels.

It has no other users, no public sign-up and no public interface. It does not read, store or display data from any other YouTube user, and it does not download or modify content from YouTube.

O PostaAi é uma ferramenta pessoal, de um único usuário, que roda só no computador do dono. Ela gera vídeos curtos verticais produzidos pelo próprio dono e os envia, pela YouTube Data API, para os dois canais do YouTube dele.

This tool uses YouTube API Services.
